# Data

## Auto download

Run any training script and the data will be downloaded here automatically.

## Manual download

1. Download from https://www.cs.toronto.edu/~kriz/cifar-10-python.tar.gz
2. Extract into this folder so the layout looks like:

```
data/
└── cifar-10-batches-py/
    ├── data_batch_1
    ├── data_batch_2
    ├── data_batch_3
    ├── data_batch_4
    ├── data_batch_5
    └── test_batch
```
